# First-round build prompt

First-round build prompt (xmltodict example, October 24, 2026). The same prompt was used for the other libraries with the library name and URL changed.
Create the equivalent of the xmltodict open source Python module (located at https://github.com/martinblech/xmltodict), but do not copy any of the existing code. You can look at the Github repository to understand what the module does, but I want you to write from scratch and not rely on any existing code. You can use the tests provided by the existing module to confirm equivalent functionality, but that activity should come later.
